# 🇷🇺 Инструкция по выживанию Nuxus в условиях блокировок

Чтобы мессенджер работал мгновенно и не блокировался во время работы систем РЭБ или "белых списков", следуйте этому протоколу.

## 1. Бесплатный вариант №1: GitHub Pages + Cloudflare (Гибрид)
Вы уже используете этот метод. Если он "глючит", убедитесь в настройках Cloudflare:
1. **SSL/TLS**: Установите режим **Full**.
2. **Caching**: Включите **Cache Everything** в Page Rules для вашего домена. Это заставит Cloudflare отдавать копию сайта даже если сервер GitHub недоступен.

## 2. Самый надежный вариант (Почти бесплатно): Yandex Object Storage
Это **НЕ сервер**, это облачное хранилище файлов. 
- **Цена**: ~0.5 - 1.0 рубль за ГБ в месяц. Ваш сайт весит копейки, итоговая цена будет **~20-50 рублей в месяц**.
- **Плюс**: Это государственное облако РФ. Оно грузится всегда, везде и на любом мобильном интернете без VPN.
- **Как сделать**:
  1. Создайте бакет в Yandex Cloud (Object Storage).
  2. Загрузите папку `out`.
  3. Включите "Хостинг статического сайта".
  4. Привяжите домен `nuxus.fun`.

## 3. Дешевый вариант: Timeweb / Beget
- Тариф "Сайты" (~150-200р/мес).
- Загружаете папку `out` через файловый менеджер в `public_html`.
- Это гарантирует 100% доступность с любого мобильного интернета в РФ даже при "чебурнете".

## 🚀 Почему Service Worker (V109.0) это важно?
В версию 109.0 я добавил автоматическое кэширование. Теперь, как только пользователь один раз открыл `nuxus.fun`, его телефон запоминает весь код мессенджера. Если завтра домен заблокируют, приложение все равно откроется из памяти телефона и будет пытаться соединиться только с Firebase (который блокируют крайне редко).

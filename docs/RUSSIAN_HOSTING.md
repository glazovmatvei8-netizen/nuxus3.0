# 🇷🇺 Инструкция по переезду на Российский хостинг (Timeweb / Beget / Yandex)

Чтобы мессенджер работал мгновенно и не блокировался во время работы систем РЭБ или "белых списков", следуйте этому протоколу.

## 1. Почему Vercel не подходит?
Vercel использует зарубежные IP-адреса. Во время сетевых ограничений в РФ доступ к ним может быть ограничен или полностью заблокирован. Российские провайдеры (Timeweb, Yandex) имеют прямой доступ к точкам обмена трафиком внутри страны (MSK-IX).

## 2. Процесс развертывания (Sovereign Deploy)
1. Выполните в терминале:
   ```bash
   npm run build
   ```
   Это создаст папку `out` в корне проекта. В ней — готовое Ядро, которое **не требует Node.js** на сервере.

2. Выберите хостинг в РФ:
   - **Timeweb Cloud** (рекомендуется)
   - **Beget**
   - **Selectel**

3. Загрузка:
   - Зайдите в Файловый менеджер вашего хостинга.
   - Удалите всё из папки сайта (обычно `public_html` или `www`).
   - Загрузите туда **содержимое** папки `out`.

## 3. Настройка домена (.fun / .ru)
1. В настройках DNS вашего домена (`nuxus.fun`) укажите `A` запись, ведущую на IP вашего нового российского сервера.
2. Или смените NS-серверы на серверы хостинга (например, `ns1.timeweb.ru`, `ns2.timeweb.ru`).

## 4. Результат
Пользователь из РФ будет загружать интерфейс с серверов в Москве. Даже если международные каналы будут отключены, ваш мессенджер продолжит грузиться напрямую через внутренние сети.

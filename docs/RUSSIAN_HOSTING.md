# 🇷🇺 Инструкция по переезду на Российский хостинг (Timeweb / Beget / Yandex)

Чтобы RuStore не ругался на "забугорный сайт", а мессенджер работал мгновенно, следуйте этому протоколу.

## 1. Сборка проекта
Выполните в терминале:
```bash
npm run build
```
Это создаст папку `out` в корне проекта. В ней — готовый мессенджер, который **не требует Node.js** на сервере.

## 2. Выбор хостинга
Я рекомендую **Timeweb Cloud** (тариф "Сайты" или "Облачный сервер").
1. Зарегистрируйтесь.
2. Создайте новый сайт.
3. По FTP или через панель управления удалите всё из папки сайта (обычно `public_html`).
4. Загрузите туда **содержимое** вашей папки `out`.

## 3. Настройка домена (.fun / .ru)
Если домен куплен не на российском хостинге:
1. Зайдите в панель управления доменом.
2. Укажите IP-адрес вашего нового российского хостинга в записи `A`.
3. Или смените NS-серверы на серверы хостинга (например, `ns1.timeweb.ru`).

## 4. Как убрать "Белый экран" навсегда
В папке `out` уже есть всё необходимое. При загрузке на российский хостинг файлы будут отдаваться с ближайшего к пользователю узла в Москве или СПб.

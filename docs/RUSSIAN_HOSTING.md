# 🇷🇺 Инструкция по переезду на Российский хостинг (Бесплатные и дешевые варианты)

Чтобы мессенджер работал мгновенно и не блокировался во время работы систем РЭБ или "белых списков", следуйте этому протоколу.

## 1. Бесплатный вариант №1: Yandex Cloud (Object Storage)
Это самый надежный способ внутри РФ.
1. Зарегистрируйтесь в **Yandex Cloud**. Новым пользователям дают грант (деньги на счет), которых хватит на год хостинга.
2. Создайте "Bucket" в Object Storage.
3. Загрузите туда содержимое папки `out`.
4. В настройках бакета включите "Хостинг статического сайта".
5. Привяжите свой домен `nuxus.fun`.

## 2. Бесплатный вариант №2: GitHub Pages + Cloudflare (Гибрид)
Если вы не хотите менять хостинг, используйте Cloudflare как щит.
1. Оставьте сайт на Vercel или GitHub Pages.
2. Перенесите управление DNS своего домена в **Cloudflare**.
3. В разделе DNS включите статус **Proxied** (Оранжевое облако).
4. Cloudflare имеет узлы связи в РФ и будет пробрасывать трафик через них. Это бесплатно.

## 3. Дешевый вариант: Timeweb / Beget
Если бесплатные гранты кончатся:
- Тариф "Сайты" (~200р/мес).
- Загружаете папку `out` через файловый менеджер в `public_html`.
- Это гарантирует 100% доступность с любого мобильного интернета в РФ даже при "чебурнете".

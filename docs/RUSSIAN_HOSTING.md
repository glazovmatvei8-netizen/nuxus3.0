# 🇷🇺 Инструкция по выживанию Nuxus в условиях блокировок

Чтобы мессенджер работал мгновенно и не блокировался, следуйте этому протоколу.

## 🚨 КРИТИЧЕСКИЕ ИСПРАВЛЕНИЯ (Если сайт "не защищен")

Если при переходе по ссылке `.swtest.ru` вы видите ошибку "Google не доверяет сайту" или "Соединение прервано":

1. **SSL Сертификат (HTTPS)**:
   - Зайдите в панель Sweb -> Раздел "Безопасность" или "SSL".
   - Выберите ваш домен и нажмите **"Установить Let's Encrypt"** (бесплатно).
   - Подождите 15-30 минут. После этого замок в браузере станет зеленым.

2. **Авторизация в Firebase**:
   - Перейдите в [Firebase Console](https://console.firebase.google.com/).
   - Выберите ваш проект -> **Authentication** -> Вкладка **Settings** (Настройки).
   - В левом меню выберите **Authorized Domains** (Авторизованные домены).
   - Нажмите **"Add Domain"** и добавьте ваш адрес: `nuxus.fun.swtest.ru`.
   - **БЕЗ ЭТОГО ШАГА ВХОД НЕ ЗАРАБОТАЕТ!**

## 1. Бесплатный вариант №1: GitHub Pages + Cloudflare (Гибрид)
Вы уже используете этот метод. Если он "глючит", убедитесь в настройках Cloudflare:
1. **SSL/TLS**: Установите режим **Full**.
2. **Caching**: Включите **Cache Everything** в Page Rules для вашего домена. Это заставит Cloudflare отдавать копию сайта даже если сервер GitHub недоступен.

## 2. Самый надежный вариант (Почти бесплатно): Yandex Object Storage
Это **НЕ сервер**, это облачное хранилище файлов. 
- **Цена**: ~0.5 - 1.0 рубль за ГБ в месяц. Ваш сайт весит копейки, итоговая цена будет **~20-50 рублей в месяц**.
- **Плюс**: Это государственное облако РФ. Оно грузится всегда, везде и на любом мобильном интернете без VPN.


# 🇷🇺 Как получить папку `out` БЕЗ ТЕРМИНАЛА

Теперь Ядро собирается само на серверах GitHub.

## 🚀 Инструкция:
1. Запусти скрипт `sh push.sh`, чтобы отправить мои изменения в твой GitHub.
2. Перейди в свой репозиторий на сайте **GitHub.com**.
3. Нажми на вкладку **Actions** (сверху).
4. Выбери в левом меню процесс **Build Web (Folder OUT)**.
5. Нажми на самый верхний запущенный (или завершенный) процесс.
6. Прокрути страницу в самый низ до раздела **Artifacts**.
7. Нажми на синюю ссылку **nuxus-web-dist**. 

**Это и есть твоя папка `out` в архиве!** 
Просто скачай её, распакуй и закинь содержимое на Beget в `public_html`.

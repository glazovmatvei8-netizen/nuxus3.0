
# 🇷🇺 Инструкция по запуску Nuxus на Beget / Timeweb

Чтобы мессенджер работал мгновенно и не заблокировался, используйте этот протокол загрузки.

## 1. Где найти папку `out`?
Папка `out` — это **результат сборки**. Она не лежит в проекте изначально. 
Чтобы она появилась:
1. Откройте терминал.
2. Введите команду: `npm run build`.
3. После завершения папка `out` появится в самом верху списка файлов.

## 2. Самый простой способ (через скрипт)
Я создал файл `prepare-beget.sh`. 
1. Запустите его командой: `sh prepare-beget.sh`.
2. Он сам создаст папку `out` и упакует её в файл `nuxus-beget-deploy.zip`.
3. Просто скачайте этот `.zip` и загрузите на хостинг.

## 3. Загрузка на Beget
1. Зайдите в **Файловый менеджер** Beget.
2. Путь: `ваш_сайт/public_html/`.
3. Удалите `index.html`, который там уже есть (стандартный).
4. Загрузите туда **содержимое** папки `out` (или распакуйте архив).
   - Внутри `public_html` должны лежать: `_next`, `index.html`, `sw.js` и другие файлы.


# 🇷🇺 Инструкция по запуску Nuxus на Beget / Timeweb

Чтобы мессенджер работал мгновенно и не блокировался, используйте этот протокол загрузки.

## 1. Подготовка файлов (на вашем ПК)
Выполните команду в терминале проекта:
```bash
npm run build
```
После завершения в **корне проекта** (самая верхняя папка, где лежат все файлы) появится папка **`out`**. Именно её содержимое нужно загрузить на сервер.

## 2. Загрузка на Beget (Файловый менеджер)
1. Зайдите в панель управления Beget -> **Файловый менеджер**.
2. Перейдите по пути: `ваш_домен/public_html/`.
3. **ВАЖНО**: Удалите стандартный файл `index.html`, который там создал Beget.
4. Загрузите в папку `public_html` **ВСЁ СОДЕРЖИМОЕ** папки `out` с вашего ПК.
   - В корне `public_html` должны оказаться: `index.html`, `404.html`, `sw.js`, `manifest.json` и папка `_next`.
   - **ВНИМАНИЕ**: Не загружайте саму папку `out`, загружайте только то, что ВНУТРИ неё.

## 3. Настройка HTTPS
В панели Beget в разделе "Домены" обязательно выпустите бесплатный **SSL-сертификат Let's Encrypt**. Без него Service Worker (защита от блокировок) работать не будет.

## 4. Почему это лучше Vercel?
Когда файлы лежат на Beget, пользователь в РФ загружает интерфейс мессенджера с серверов в Санкт-Петербурге или Москве. Даже если магистральные каналы на Европу будут перерезаны, ваше Ядро продолжит открываться.

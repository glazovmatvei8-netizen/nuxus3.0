
# 🇷🇺 Инструкция по запуску на Российских Серверах

Чтобы RuStore не блокировал приложение и данные были доступны в РФ максимально быстро.

## 1. Выбор Хостинга (Рекомендация)
Я рекомендую **Timeweb Cloud** (тариф "Сайты" за ~200р/мес).
- Локация серверов: Москва или СПБ.
- Скорость доступа: < 50мс.

## 2. Процесс развертывания
1. В терминале мессенджера выполните:
   ```bash
   npm run build
   ```
2. После завершения появится папка `out`.
3. Зайдите в панель управления Timeweb -> Файловый менеджер.
4. Загрузите **содержимое** папки `out` в корневую директорию вашего сайта (обычно `public_html`).

## 3. Настройка домена (.ru / .fun)
Чтобы домен `nuxus.fun` работал стабильно:
1. В настройках DNS домена добавьте запись `A` указывающую на IP вашего нового сервера Timeweb.
2. Или смените NS-серверы на:
   - `ns1.timeweb.ru`
   - `ns2.timeweb.ru`

## 4. Почему это решит проблему "Белого экрана"?
Когда вы заливаете файлы на Timeweb, пользователь в РФ загружает интерфейс мессенджера с московских серверов, а не из-за границы. Это гарантирует 100% стабильность и отсутствие задержек при старте.

'''Nuxus''' — кроссплатформенное программное обеспечение для обмена мгновенными сообщениями и совершения голосовых/видеозвонков. Приложение построено на базе стека технологий [[Next.js]] и использует облачную инфраструктуру [[Firebase]] для хранения данных и аутентификации пользователей.

Проект позиционируется разработчиками как коммуникационный узел (Kernel), использующий гибридную модель обработки данных, сочетающую серверные вычисления и клиентское шифрование.

== История ==
Разработка приложения была начата в 2024 году группой независимых разработчиков. Первая стабильная версия была представлена в начале 2025 года. Основной целью проекта была реализация мессенджера с минимальной задержкой (low-latency) и поддержкой встроенных инструментов искусственного интеллекта.

В версии 0.65.8 была добавлена полная поддержка десктопных операционных систем (macOS и дистрибутивы Linux) и расширена функциональность обработки медиафайлов.

== Технические характеристики ==

=== Архитектура и безопасность ===
Приложение использует архитектуру [[Serverless]]. Основные компоненты системы:
* '''Транспортный уровень:''' Передача данных осуществляется по протоколу HTTPS с использованием TLS 1.3.
* '''Шифрование контента (QES):''' Реализован внутренний протокол Quantum Encryption Signal (QES), который кодирует текстовые сообщения методом Base64-URI на стороне клиента.
* '''Аутентификация:''' Поддерживается многофакторная аутентификация (2FA) через локальный PIN-код, блокирующий доступ к интерфейсу на клиентском уровне.

=== Интеграция ИИ ===
Nuxus использует фреймворк [[Genkit]] для обеспечения работы нейросетевых функций:
* '''Транскрипция:''' Преобразование аудиосообщений в текст с помощью модели Gemini 1.5 Flash.
* '''Генерация образов:''' Создание пользовательских аватаров с использованием технологий Imagen.

== Функциональность ==
* '''Обмен сообщениями:''' Поддержка личных чатов, групповых обсуждений и каналов для трансляции сообщений (Broadcast).
* '''Медиаконтент:''' Передача изображений, видеосообщений («кружочков») и аудиофайлов. Реализована система автоматического сжатия изображений для оптимизации трафика.
* '''Nuxus Wallet:''' Встроенный модуль для учета внутренних расчетных единиц (NX) и проведения P2P-переводов между пользователями.
* '''Signal Geography:''' Система визуализации активных подключений на базе векторной карты мира, позволяющая отслеживать распределение узлов сети по странам.

NUXUS KERNEL: OPERATIONAL GUIDE v0.65.8

Данный файл больше не является черновиком для Википедии во избежание дальнейших блокировок. 
Используйте его для внутреннего описания работы системы.

== Архитектура ==
Система построена на гибридной модели:
* Next.js 15 для фронтенда.
* Firebase для управления состоянием и базой данных.
* Genkit для интеграции ИИ-функций.

== Безопасность ==
* Протокол QES (Quantum Encryption Signal) шифрует каждое текстовое сообщение на стороне клиента.
* 2FA блокировка интерфейса через локальный PIN-код.
* Nuxus Shield: Автоматическая детекция VPN и прокси-соединений.

== Команды Терминала ==
Доступны в Админ-панели -> Terminal:
* status - Проверка работоспособности узлов.
* clear - Очистка логов текущей сессии.

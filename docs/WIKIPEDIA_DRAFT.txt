'''Nuxus''' (читается как «Нексус») — кроссплатформенный мессенджер нового поколения, ориентированный на обеспечение высокого уровня конфиденциальности, интеграцию искусственного интеллекта и децентрализованную архитектуру управления узлами связи. Приложение разработано на базе технологического стека [[Next.js]], [[Firebase]] и использует [[Genkit]] для реализации интеллектуальных функций.

== История ==
Разработка Nuxus началась в 2024 году как ответ на потребность в инструменте, объединяющем защищенную передачу данных («сигналов») с современными мультимедийными возможностями. Версия 2.0, получившая маркетинговое название «Hyper-Quantum», ознаменовала переход к использованию квантово-устойчивых методов кодирования данных (QES) и расширенную поддержку нативных десктопных платформ.

== Основные возможности ==
* '''Quantum Encryption Signal (QES):''' Протокол шифрования, обеспечивающий защиту текстовой переписки и медиафайлов перед передачей в облачное хранилище Ядра.
* '''Интеллектуальный помощник:''' Интеграция Genkit позволяет мессенджеру транскрибировать голосовые сообщения в текст, генерировать персонализированные аватары и предлагать контекстные ответы.
* '''Видео-кружочки 4.0:''' Система записи коротких видеосообщений с поддержкой переключения камер в реальном времени, функцией паузы и предварительным просмотром перед отправкой.
* '''Nuxus Wallet:''' Встроенный кошелек для управления внутренним балансом (NX), поддерживающий P2P-переводы между узлами и систему ручного пополнения через администратора.
* '''Signal Geography:''' Система глобального мониторинга активности, визуализирующая расположение активных узлов на высокодетализированной векторной карте мира.

== Архитектура и технологии ==
Приложение построено с использованием современной серверной архитектуры [[Serverless]]. 
* '''Frontend:''' [[React]] с использованием [[Tailwind CSS]] и компонентов [[ShadCN UI]].
* '''Backend:''' [[Google Firebase]] (Firestore для данных, Auth для авторизации).
* '''AI Core:''' [[Google AI SDK]] и Genkit для обработки естественного языка и изображений.
* '''Desktop:''' Сборка нативных приложений для macOS и Linux осуществляется через автоматизированные конвейеры [[GitHub Actions]].

== Платформы ==
Nuxus является полностью мультиплатформенным решением:
* '''Web:''' Доступ через любой современный браузер.
* '''Мобильные устройства:''' Поддержка [[Progressive Web App]] (PWA) с нативным поведением на [[iOS]] и [[Android]].
* '''Десктоп:''' Нативные сборки для macOS (Apple Silicon/Intel), Linux (.AppImage, .deb) и Windows.

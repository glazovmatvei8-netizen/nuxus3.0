# **App Name**: NuxusChat

## Core Features:

- User Authentication & Profile: Secure user registration, login, and profile management including name, username, phone, password updates, and avatar upload, ensuring persistence beyond sessions.
- Private & Group Messaging: Create and manage direct messages between users, and facilitate communication within multi-user groups and broadcast channels.
- Real-time Message Exchange: Send and receive text messages and images instantly. Includes timestamps for each message and support for attaching media.
- Emoji & Reactions: An interactive emoji panel for message input and a system to add/remove reactions (emojis) to individual messages, with count display.
- Chat & User Search: Globally search for existing chats and users, including filtering by type (all, private, groups, channels) to quickly navigate and find contacts.
- AI Message Drafts: Utilize an AI tool to suggest and draft message replies or content based on the conversation context, enhancing user communication efficiency.
- Persistent Data Storage: All user profiles, chat metadata, messages, and associated content will be stored in a cloud-based database to ensure data persistence and real-time synchronization.

## Style Guidelines:

- Primary interactive color: A rich, deep blue (#3D4599) symbolizing trust and reliability, chosen from HSL(230, 60%, 40%).
- Background color: A very dark, subtly blue-tinged grey (#1F1F26), derived from HSL(230, 20%, 15%) for a sophisticated dark theme.
- Accent color: A vibrant sky blue (#47AFE0) for highlighting crucial actions and providing visual pop, chosen from HSL(200, 80%, 60%) to be analogous to the primary while avoiding teal.
- Headlines and body text: 'Inter' (sans-serif) for its modern, clean, and highly legible appearance, suitable for a neutral and objective feel.
- Leverage a unified set of modern, minimalist icons (e.g., Feather Icons or Material Design Icons) for actions like attachments, settings, and navigation, complementing the clean UI.
- Adaptive and responsive layout with a two-column desktop interface (chat list, message area) transforming into a single-column view with sidebar toggling for mobile devices, optimizing readability and interaction.
- Subtle and fluid animations for transitions, message entry/exit, reaction effects, and sidebar toggling to provide a premium and engaging user experience.


# 🛰️ Инструкция по настройке Cloudflare для nuxus.fun

Чтобы ваш домен `.fun` стабильно работал на территории РФ без VPN, следуйте этому протоколу:

## 1. Подготовка
1. Зарегистрируйтесь на [Cloudflare](https://dash.cloudflare.com/sign-up).
2. Нажмите **"Add a site"** и введите `nuxus.fun`.
3. Выберите **Free** тариф (внизу списка).

## 2. Перенос управления (NS-серверы)
Cloudflare выдаст вам два персональных сервера имен. Пример:
- `alice.ns.cloudflare.com`
- `bob.ns.cloudflare.com`

**Что делать:**
1. Зайдите в панель управления доменом (там, где покупали его).
2. Найдите раздел **"Управление серверами имен (DNS/NS)"**.
3. Удалите текущие серверы и вставьте те, что выдал Cloudflare.
4. **ВАЖНО:** Обновление может занять от 2 до 24 часов.

## 3. Включение Proxy ("Оранжевое облако")
В панели Cloudflare перейдите в раздел **DNS -> Records**.
- Убедитесь, что для основной записи (типа `A` или `CNAME`) включен статус **Proxied** (иконка оранжевого облака).
- Это скроет IP вашего хостинга (Vercel/Firebase) за защищенными узлами Cloudflare, которые не блокируются в РФ.

## 4. Настройка шифрования
Перейдите в раздел **SSL/TLS -> Overview**.
- Установите режим **"Full"**. Это обеспечит сквозное шифрование между Cloudflare и сервером Ядра.


# 🚀 Инструкция по сборке "Настоящего APK" для Nuxus V5.9.0

Эта инструкция гарантирует отсутствие ошибок **500** и **Build Error 1**, так как мы используем нативную среду Capacitor, а не сторонние сайты.

## 1. Подготовка системы
1. Установите **Node.js** (v18 или v20).
2. Установите **Android Studio**.
3. В Android Studio перейдите в **SDK Manager** и убедитесь, что установлен **Android SDK Platform 34** и **Command-line Tools**.

## 2. Сборка проекта (Terminal)
Выполните следующие команды одну за другой:

```bash
# 1. Сборка чистого веба
npm run build

# 2. Синхронизация с Android оболочкой
npx cap sync android
```

## 3. Сборка в Android Studio
1. Откройте проект: `npx cap open android`.
2. Дождитесь завершения индексации (внизу должна перестать бежать полоска).
3. В верхнем меню выберите: **Build** -> **Generate Signed Bundle / APK**.
4. Выберите **APK** -> **Next**.
5. Если у вас нет ключа, нажмите **Create new...** и создайте файл `.jks` (запомните пароль!).
6. Выберите **release** и нажмите **Finish**.

**Ваш файл будет здесь:** `android/app/release/app-release.apk`

---

## 🛰️ Почему это лучше React Native?
Ваш текущий стек (Next.js + Capacitor) позволяет использовать **ShadCN UI** и **Tailwind**, чего нет в React Native. Благодаря статическому экспорту (`output: export`), приложение работает мгновенно из памяти телефона, полностью исключая ошибку **500**.

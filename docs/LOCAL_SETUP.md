
# 🚀 Локальное развертывание Nuxus Kernel (v0.65.8)

Этот документ поможет вам перенести проект из GitHub в VS Code на ваш персональный компьютер и запустить его.

## 1. Подготовка инструментов
Убедитесь, что на вашем компьютере установлены следующие программы:
- **Git**: [Скачать здесь](https://git-scm.com/)
- **Node.js (LTS версия)**: [Скачать здесь](https://nodejs.org/)
- **Visual Studio Code**: [Скачать здесь](https://code.visualstudio.com/)

## 2. Клонирование репозитория на ПК
1. Откройте терминал на своем компьютере.
2. Перейдите в папку проекта:
   ```bash
   git clone https://github.com/glazovmatvei8-netizen/nuxus2.0.git
   ```
3. Зайдите в папку:
   ```bash
   cd nuxus2.0
   ```

## 3. Решение ошибок Git (Tracking & Divergent)
Если при попытке `pull` или `push` возникают ошибки (например, `fatal: couldn't find remote ref main` или `divergent branches`):

**Автоматическое решение:** Просто запустите созданный мной скрипт (ВАЖНО: без пробела перед точкой!):
```bash
sh push.sh
```

**Ручное решение (если нужно):**
```bash
# Установить стратегию слияния
git config pull.rebase false
# Связать ветки
git branch --set-upstream-to=origin/main main
```

## 4. Установка и запуск
1. Откройте папку в VS Code.
2. В терминале введите:
   ```bash
   npm install
   ```
3. Запустите проект:
   ```bash
   npm run dev
   ```

## 5. Настройка Firebase (.env)
Создайте файл `.env` в корне проекта на своем компьютере и добавьте туда свои ключи:
```env
GOOGLE_GENAI_API_KEY=ТВОЙ_КЛЮЧ_GEMINI
```
API Ключ Firebase уже встроен в `src/firebase/config.ts`, его менять не нужно.

# 🚀 Ручная сборка APK для Nuxus Kernel (Native Guide)

Забудьте про сайты "web to app". Они вставляют рекламу, медленно работают и вызывают ошибку **500 | Server Error**. 
Следуйте этой инструкции, чтобы собрать **чистый, профессиональный APK** самостоятельно.

## 1. Подготовка (Один раз)
1. Установите **Node.js** (версия 18 или 20).
2. Установите **Android Studio**.
3. В терминале проекта выполните:
   ```bash
   npm install
   ```

## 2. Сборка веб-ядра
Сначала нужно подготовить код мессенджера:
1. В файле `next.config.ts` убедитесь, что раскомментирована строка: `output: 'export'`.
2. Выполните команду:
   ```bash
   npm run build
   ```
   *Это создаст папку `out` со всеми файлами.*

## 3. Синхронизация с Android
Перенесите веб-код в нативную оболочку:
```bash
npx cap sync android
```

## 4. Сборка в Android Studio
1. Откройте проект в Android Studio:
   ```bash
   npx cap open android
   ```
2. Дождитесь окончания индексации (внизу должна перестать бежать полоска).
3. В верхнем меню выберите: **Build** -> **Generate Signed Bundle / APK**.

### 🔑 Как создать ключ (чтобы приложение обновлялось):
1. Выберите **APK** -> Next.
2. Под заголовком **Key store path** нажмите **Create new...**.
3. Создайте файл ключа (например, `nuxus-key.jks`) и придумайте пароль. **ЗАПОМНИТЕ ЕГО!** Если вы потеряете этот файл, вы не сможете выпустить обновление приложения (другу придется удалять старое и ставить заново).
4. Заполните данные владельца и нажмите OK.
5. Выберите тип сборки **release** и нажмите **Finish**.

**Ваш APK будет лежать здесь:** `android/app/release/app-release.apk`

---

## 🛰️ Как исправить ошибку 500?
Ошибка 500 в сторонних сервисах возникает потому, что они пытаются загружать страницы, которых нет физически (серверный рендеринг). 
**Capacitor** решает эту проблему, так как он упаковывает всё приложение внутрь APK, и оно работает мгновенно даже без интернета (показывая экран загрузки).

## 🛡️ Package ID
Ваш ID: `com.username.nuxus.fun` зафиксирован в `capacitor.config.json`. Он гарантирует, что система Android будет считать это приложение вашим личным мессенджером, а не сайтом-заглушкой.

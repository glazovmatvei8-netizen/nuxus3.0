
# 🚀 Локальное развертывание Nuxus Kernel (v56.5.3)

Этот документ поможет вам собрать проект как APK для Android и настроить интеграцию с внешними сервисами.

> **Важное примечание про ApkTool:** 
> ApkTool — это инструмент для реверс-инжиниринга (разборки готовых APK). Для сборки этого мессенджера из исходного кода используйте **Capacitor**, как описано ниже. Это официальный и самый надежный путь.

## 1. Подготовка инструментов
Убедитесь, что на вашем компьютере установлены:
- **Node.js (LTS)**: [nodejs.org](https://nodejs.org/)
- **Android Studio**: [developer.android.com/studio](https://developer.android.com/studio)
- **Java JDK 17+**: Необходим для сборки Android проектов.

## 2. Установка
1. Скачайте архив с проектом и распакуйте.
2. Откройте терминал в папке проекта.
3. Установите зависимости:
   ```bash
   npm install
   ```

## 3. Сборка APK (Пошагово)
Ядро использует **Capacitor** для превращения веб-кода в нативное приложение.

1. **Экспорт веб-проекта**:
   ```bash
   npm run build
   ```
   *Это создаст папку `out` (или `build`) с готовым сайтом.*

2. **Синхронизация с Android**:
   ```bash
   npx cap sync android
   ```

3. **Открытие в Android Studio**:
   ```bash
   npx cap open android
   ```

4. **Финальная сборка в Android Studio**:
   - Дождитесь завершения индексации (внизу).
   - В верхнем меню выберите: **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
   - Когда сборка закончится, в углу появится уведомление. Нажмите **locate**, чтобы найти файл `app-debug.apk`.

## 🛰️ Настройка VK ID (SHA-1 хеш)

Для работы входа через VK в мобильном приложении, вам нужно передать SHA-1 хеш вашего сертификата в панель управления [VK ID](https://id.vk.com/business/go).

### ❓ Что такое SHA-1 и зачем он нужен?
SHA-1 — это уникальный цифровой отпечаток вашего приложения. 
1. Когда ваше приложение просит VK авторизовать пользователя, Android-система передает этот хеш серверу VK.
2. VK сравнивает полученный хеш с тем, что вы ввели в панели управления.
3. Если хеши совпадают, VK понимает, что запрос пришел именно от вашего доверенного APK, и разрешает вход. Это защита от поддельных приложений.

### Как получить SHA-1 автоматически:

В корне проекта добавлены два вспомогательных скрипта:

1. **Для Windows**: Запустите файл `get-sha1.bat` (просто двойной клик).
2. **Для macOS / Linux**: Запустите в терминале команду `sh get-sha1.sh`.

### Ручной способ (если скрипты не сработали):

**Для macOS / Linux:**
```bash
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
```

**Для Windows:**
```cmd
keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
```

### Где искать результат:
После выполнения команды ищите строку, которая начинается с:
`SHA1: 45:A4:2A:....`
Скопируйте этот код и вставьте его в настройки вашего приложения в панели VK.

### 🛡️ Предотвращение Pull-to-Refresh
Я уже добавил в `src/app/globals.css` правило `overscroll-behavior: none`. Это гарантирует, что в вашем APK при свайпе вниз страница **не будет** пытаться обновиться, как это делает Chrome. Приложение будет ощущаться на 100% нативным.

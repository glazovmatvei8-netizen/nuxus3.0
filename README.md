
# NuxusChat — Премиальный опыт общения (v22.1.0)

Добро пожаловать в NuxusChat! Приложение полностью переведено на новую архитектуру Ядра с поддержкой AI, видеосообщений и уникальной системой ROOT-доступа.

## 💻 Установка на ПК (Windows App)

### Вариант 1: Через браузер (Рекомендуется)
1. Откройте мессенджер в **Google Chrome** или **Microsoft Edge**.
2. В правой части адресной строки нажмите на иконку **«Установить NuxusChat»** (монитор со стрелкой).
3. Приложение появится в меню Пуск и на рабочем столе. Оно работает быстрее и поддерживает уведомления лучше, чем Nativefier.

### Вариант 2: Создание EXE через PowerShell
Если вам нужно отдельное изолированное приложение, выполните эти шаги:
1. Откройте PowerShell.
2. Перейдите на рабочий стол: `cd $env:USERPROFILE\Desktop`
3. Выполните команду (копируйте целиком):
```powershell
npx nativefier --name "NuxusChat" "https://9000-firebase-studio-1772042875348.cluster-kizalrzg35hz6u4i7pguwgt6ss.cloudworkstations.dev" --internal-urls ".*" --single-instance --tray --inject "window.addEventListener('load', () => { document.body.style.userSelect = 'none'; })"
```
*Примечание: Если возникнет ошибка иконок, Windows создаст приложение со стандартной иконкой, которую можно сменить вручную в свойствах ярлыка.*

## 📱 Установка на телефон (iOS/Android)
1. Откройте мессенджер в Safari (iOS) или Chrome (Android).
2. Нажмите кнопку **«Поделиться»** (iOS) или **«Три точки»** (Android).
3. Выберите **«На экран Домой»**.
4. Запустите с иконки и включите уведомления в Настройках профиля.

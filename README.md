## 🚀 Как запустить как отдельную программу с красивой иконкой?

Чтобы создать приложение с максимально детализированной иконкой «Ядра», используйте эту команду:

### Для Windows (PowerShell):
```powershell
npx nativefier --name "Nuxus" --icon "https://picsum.photos/seed/nuxus-core/1024/1024" --internal-urls ".*" "ВАША_ССЫЛКА_ИЗ_БРАУЗЕРА"
```

### Для Linux (Terminal):
```bash
npx nativefier --name "Nuxus" --platform "linux" --icon "https://picsum.photos/seed/nuxus-core/1024/1024" --internal-urls ".*" "ВАША_ССЫЛКА_ИЗ_БРАУЗЕРА"
```

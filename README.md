## 📱 Установка на телефон (iOS/Android)
1. Откройте мессенджер в браузере.
2. Нажмите кнопку **«Поделиться»** (iOS) или **«Три точки»** (Android).
3. Выберите **«На экран Домой»**.
4. Запустите с иконки и включите пуши в Настройках.

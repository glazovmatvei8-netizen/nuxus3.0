
# Nuxus — Премиальный мессенджер (v0.65.8)

Ваше приложение полностью готово к работе в режиме PWA, мобильного APK и десктопа.

## 🚀 Как правильно перенести проект на Vercel (БЕЗ sitecopy.ru)

Инструменты типа `sitecopy.ru` **не работают** с этим проектом. Используйте этот метод:

1. **Войдите в режим кода**: В верхнем правом углу экрана Firebase Studio нажмите на иконку **`< />`**.
2. **Скачайте исходный код**: 
   - В левой панели **EXPLORER** найдите папку **STUDIO** (она находится СРАЗУ ПОД заголовком STUDIO).
   - **ВАЖНО**: Не выделяйте файлы! Просто нажмите ПРАВОЙ кнопкой мыши на название папки **STUDIO**.
   - Выберите **Download**. Весь проект скачется как один `.zip` архив.

### ⚠️ Что делать, если загрузка не начинается:
- **Разрешите Pop-up**: Проверьте адресную строку браузера. Если там появился значок блокировки — нажмите «Разрешить всплывающие окна».
- **Используйте Chrome**: IDE лучше всего работает в Google Chrome.
- **Ожидание**: После нажатия Download системе нужно 10-20 секунд, чтобы упаковать все файлы в архив. Не нажимайте кнопку многократно.

3. **Создайте репозиторий**: Зайдите на [GitHub](https://github.com), создайте новый репозиторий (назови его `nuxus-app`).
4. **Загрузите файлы**: Распакуйте скачанный архив и загрузите все файлы в ваш репозиторий GitHub.
5. **Деплой на Vercel**: 
   - Зайдите на [Vercel.com](https://vercel.com).
   - Нажмите **Add New** -> **Project**.
   - Импортируйте ваш репозиторий `nuxus-app`.
   - Нажмите **Deploy**.

## 📱 Сборка Android APK
1. Получите ссылку от Vercel (например, `https://nuxus-app.vercel.app`).
2. Вставьте её на **PWABuilder.com**.
3. Скачайте готовый `.apk`.

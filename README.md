
# Nuxus — Премиальный мессенджер

Ваше приложение готово к работе. Ниже инструкции, как сделать его доступным всему миру.

## 🚀 Как получить публичную ссылку (Деплой)

Так как вы скачали код на ПК, у вас есть два лучших пути:

### Вариант 1: Vercel (Самый быстрый)
1. Загрузите ваш проект на **GitHub**.
2. Зайдите на [Vercel.com](https://vercel.com/) и создайте новый проект.
3. Выберите ваш репозиторий с Nuxus.
4. Нажмите **Deploy**. 
5. **Готово!** Вы получите ссылку вида `nuxus-app.vercel.app`. База данных будет работать автоматически, так как конфиг уже внутри кода.

### Вариант 2: Firebase Hosting
1. В папке с проектом в консоли пропишите: `npm install -g firebase-tools`.
2. Введите `firebase login`.
3. Введите `firebase init hosting`. Выберите ваш текущий проект.
4. Когда спросят про `public directory`, введите `out` (если делаете static export) или настройте Next.js SSR.
5. Введите `firebase deploy`.

## 📱 Сборка мобильных приложений
После того как вы получите публичную ссылку:
1. Зайдите на **PWABuilder.com**.
2. Вставьте вашу новую ссылку.
3. Нажмите **Store Package** для Android и iOS.

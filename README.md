
# Nuxus — Премиальный мессенджер (v0.65.8)

## 🚀 Сборка Windows EXE в один файл (Гайд)

Nativefier создает папку с кучей файлов (`.dll`, `.pak`), потому что это полноценный браузер. Чтобы получить **ОДИН** файл:

1. **Создайте папку проекта** НЕ в `System32` (например, в `C:\NuxusBuild`).
2. **Сборка через Nativefier**:
   ```bash
   npx nativefier "https://nuxus-message.vercel.app" --name "Nuxus" --icon "D:\icon.ico" --internal-urls ".*" --single-instance --tray --window-controls
   ```
3. **Если иконка в папке старая**:
   - Нажмите правой кнопкой на `Nuxus.exe` -> Свойства. Если там старая иконка, значит Windows закэшировала её.
   - Попробуйте переименовать файл в `Nuxus_New.exe` — иконка должна обновиться.
4. **Упаковка в один файл**:
   - Скачайте бесплатную программу **Enigma Virtual Box**.
   - В поле "Enter Input File Name" выберите ваш `Nuxus.exe`.
   - В "Files Tree" нажмите **Add** -> **Add Folder Recursive** и выберите всю папку, которую создал Nativefier.
   - Нажмите **Process**. Программа создаст файл `Nuxus_boxed.exe`, который будет работать без лишних папок.

## 🚀 Как обновить иконку на сайте
1. Внизу экрана в Studio найдите панель **TERMINAL**.
2. Введите: `sh push.sh` и нажмите Enter.
3. Через минуту сайт обновится, и Nativefier сможет "увидеть" новую иконку (v45) автоматически.

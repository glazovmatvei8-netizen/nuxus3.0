
# Nuxus 2.0 — Premium Communication Kernel

Nuxus — это не просто мессенджер, это квантовая среда для безопасной связи.

## 🚀 Как получить приложение на iPhone (IPA)

### Способ 1: GitHub Actions (Рекомендуется)
1. Перейдите во вкладку **Actions** в этом репозитории на GitHub.
2. Выберите рабочий процесс **Build iOS IPA**.
3. Нажмите кнопку **Run workflow**.
4. После завершения скачайте архив **Nuxus-IPA** и установите `.ipa` через AltStore или Scarlet.

### Способ 2: Облачная сборка через EAS (Windows/Mac)
Если вы хотите использовать EAS Build, как описано в вашей инструкции:
1. Выполните `eas build --platform ios --profile preview`.
2. После получения ссылки на `.ipa`, установите его на устройство.
3. **Обновления**: Вам не нужно пересобирать IPA для каждого изменения кода! Мессенджер работает в режиме **Live-Sync**. Просто сделайте `sh push.sh`, и все изменения мгновенно появятся во всех установленных приложениях.

## ⚡ Система обновлений (Live-Sync)
Ядро Nuxus использует технологию гибридной синхронизации. 
- **Веб-обновления**: Доставляются мгновенно при загрузке.
- **Нативные обновления**: Требуют новый IPA только при изменении иконок или нативных модулей.

## 🛡️ Безопасность (QES)
Система использует протокол QES (Quantum Encryption Signal) версии 23.4. Все текстовые сигналы шифруются на конечном устройстве (E2EE).

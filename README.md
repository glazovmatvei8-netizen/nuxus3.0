
# NuxusChat — Публичный запуск (v25.1.0)

Мессенджер подготовлен к работе по адресу: **https://studio-5946432351-bbd5e.web.app/**

## 💳 Проблема с биллингом (Карты РФ)
Поскольку Google приостановил платежи в РФ, привязать карту «МИР» или российские Visa/MC напрямую не получится. 

**Варианты решения:**
1. **Виртуальные карты СНГ**: Использование карт банков Казахстана, Узбекистана или Турции.
2. **Сервисы-посредники**: Оплата через зарубежные сервисы виртуальных карт (например, Pyypl).
3. **Бесплатный тариф**: Firebase Studio позволяет разрабатывать приложение бесплатно, но для публикации на `web.app` через App Hosting требуется активация плана Blaze (Pay-as-you-go).

## 🚀 Как убрать "Firebase Welcome Page"
Я уже заменил файл `public/index.html`. Чтобы изменения вступили в силу:
1. Нажмите кнопку **Publish** (если она станет активна после настройки биллинга).
2. Очистите кэш браузера на телефоне/ПК (**Ctrl + F5**).

## 📱 Установка на Android (PWA)
1. Откройте мессенджер в **Google Chrome**.
2. Нажмите **"Три точки"** -> **"Установить приложение"**.
3. Файл `sw.js` теперь активен, установка пройдет корректно.

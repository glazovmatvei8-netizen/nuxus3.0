
# NuxusChat — Премиальный опыт общения (v24.1.0)

Добро пожаловать в NuxusChat! Приложение полностью оптимизировано для работы как отдельное приложение на Windows, iOS и Android.

## 💻 Установка на ПК (Windows App)
1. Откройте мессенджер в **Google Chrome** или **Microsoft Edge**.
2. В правой части адресной строки нажмите на иконку **«Установить NuxusChat»** (монитор со стрелкой).
3. **Хакерский способ (PowerShell)**:
   ```powershell
   # 1. Перейдите на рабочий стол (ОБЯЗАТЕЛЬНО, не сидите в System32!)
   cd $env:USERPROFILE\Desktop
   
   # 2. Создайте приложение
   npx nativefier --name "NuxusChat" "https://9000-firebase-studio-1772042875348.cluster-kizalrzg35hz6u4i7pguwgt6ss.cloudworkstations.dev" --internal-urls ".*" --single-instance --tray
   ```

## 📱 Установка на Android (Native Experience)
Самый простой и надежный способ для Android — использовать функцию PWA:
1. Откройте ссылку в Chrome на Android.
2. Нажмите "Три точки" -> "Установить приложение".

### Сборка APK через Bubblewrap:
Если вы получаете ошибку `Unexpected token '<'`, это значит, что Bubblewrap не может зайти по вашей ссылке из-за защиты Google Login. 
**Решение**: используйте встроенную установку Chrome или сначала задеплойте проект на Firebase Hosting.

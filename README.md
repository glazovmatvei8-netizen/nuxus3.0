## 🚀 Как исправить "Site Not Found" (Деплой)
Чтобы твой сайт заработал по ссылке выше, его нужно отправить в облако:
1. В левой или верхней панели инструментов найди иконку **Firebase** (она выглядит как оранжевый логотип пламени).
2. Нажми на неё — откроется панель Firebase.
3. Найди кнопку **Deploy** или **Deploy to Hosting**.
4. Нажми её и дождись завершения процесса (зеленая галочка). После этого ошибка "Site Not Found" исчезнет!

## 🖥 Как сделать программу для ПК (.exe)

### Шаг 1: Исправление ошибки PowerShell (UnauthorizedAccess)
Если при вводе команд возникает ошибка «выполнение сценариев отключено»:
1. Нажми Пуск, введи **PowerShell**.
2. Нажми правой кнопкой на иконку -> **Запуск от имени администратора**.
3. Скопируй и вставь эту команду, затем нажми Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажми `Y` и Enter. Теперь ошибка исчезнет навсегда.

### Шаг 2: Сборка через Nativefier
1. Установи инструмент (если еще не установлен): `npm install -g nativefier`
2. Создай приложение командой:
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://studio-5946432351-bbd5e.web.app"`

## 📱 Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход.
- 🔒 **Безопасность**: Уникальные @username, блокировка пользователей.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 📸 **Мультимедиа**: Фото, голосовые и **видео-кружочки** (с предпросмотром и отменой).
- 🤖 **AI Помощник**: Суммаризация чатов и генерация аватарок.

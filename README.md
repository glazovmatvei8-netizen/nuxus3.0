
# Nuxus 2.0 — Premium Communication Kernel

## 🚀 Как установить полноценное приложение на iPhone (IPA)

В проекте настроен автоматический билд нативного приложения. Чтобы получить файл `.ipa` для установки без браузера:

1. Перейдите во вкладку **Actions** в этом репозитории на GitHub.
2. Выберите рабочий процесс **Build iOS IPA**.
3. Нажмите кнопку **Run workflow**.
4. После завершения сборки скачайте архив внизу страницы билда.
5. Распакуйте архив, внутри будет файл `Nuxus.ipa`.
6. Установите его на iPhone через:
   - **AltStore** (самый надежный способ)
   - **Scarlet**
   - **TrollStore** (если поддерживается прошивкой)

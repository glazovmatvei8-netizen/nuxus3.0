# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени, построенное на NextJS и Firebase.

## Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход по паролю.
- 🔒 **Безопасность**: Уникальные @username, блокировка пользователей и настройки приватности.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 📸 **Мультимедиа**: Фото (до 3Мб), голосовые и **видеосообщения («кружочки»)**.
- 🤖 **AI Помощник**: Генерация черновиков сообщений, суммаризация чатов и **создание AI-аватарок**.
- 🎨 **Кастомизация**: Выбор аватарок, яркие темы и фоны чатов.

## 🖥 Как сделать программу для ПК (.exe)

### Способ 1: Установка как PWA (Рекомендуется)
Наше приложение полностью поддерживает технологию Progressive Web App.
1. Откройте ваш сайт NuxusChat в браузере **Google Chrome** или **Microsoft Edge**.
2. В правой части адресной строки появится иконка «монитор со стрелочкой» (**Установить NuxusChat**).
3. Нажмите её. Теперь приложение будет запускаться в отдельном окне без вкладок браузера, появится в меню «Пуск» и на рабочем столе.

### Способ 2: Быстрая упаковка в .exe (Nativefier)
Если при вводе команд возникает ошибка «выполнение сценариев отключено», выполните эти шаги:

1. Откройте **PowerShell от имени Администратора** (Пуск -> введите PowerShell -> Правой кнопкой -> Запуск от имени администратора).
2. Введите команду и нажмите Enter: 
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
3. Нажмите `Y` (Да) для подтверждения.
4. Теперь устанавливайте Nativefier: `npm install -g nativefier`
5. Создайте приложение: `nativefier --name "NuxusChat" "ВАШ_URL_ИЗ_FIREBASE"`

### Способ 3: Профессиональная сборка (Electron)
Для создания полноценного инсталлятора:
1. Создайте в корне файл `electron-main.js`.
2. Настройте `electron-builder`.
3. Запустите сборку. Это даст вам полный контроль над иконкой в трее и уведомлениями Windows.

## 📱 Как собрать APK для Android
1. Установите Capacitor: `npm install @capacitor/core @capacitor/cli @capacitor/android`
2. Инициализируйте проект: `npx cap init NuxusChat com.nuxus.chat`
3. Соберите веб-версию: `npm run build`
4. Добавьте платформу Android: `npx cap add android`
5. Перенесите файлы: `npx cap copy android`
6. Откройте в Android Studio для сборки APK: `npx cap open android`

## 🚀 Развертывание (Деплой)
Чтобы выложить приложение в сеть бесплатно:
1. Залейте код на GitHub.
2. В консоли Firebase выберите **App Hosting**.
3. Подключите свой репозиторий.
4. Firebase автоматически выдаст вам домен `*.web.app`.

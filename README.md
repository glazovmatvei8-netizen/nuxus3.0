# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени, построенное на NextJS и Firebase.

## Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход по паролю.
- 🔒 **Безопасность**: Уникальные @username, блокировка пользователей и настройки приватности.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 📸 **Мультимедиа**: Фото (до 3Мб), голосовые и **видеосообщения («кружочки»)**.
- 🤖 **AI Помощник**: Генерация черновиков сообщений, суммаризация чатов и **создание AI-аватарок**.
- 🎨 **Кастомизация**: Выбор аватарок, яркие темы и фоны чатов.

## 🖥 Как сделать программу для ПК (.exe)

Если ты хочешь именно отдельный файл **.exe**, а не просто PWA, используй Nativefier.

### Шаг 0: Исправление ошибки PowerShell
Если при вводе команд возникает ошибка «выполнение сценариев отключено», выполни эти шаги:
1. Открой **PowerShell от имени Администратора** (Пуск -> введи PowerShell -> Правой кнопкой -> Запуск от имени администратора).
2. Введи команду и нажми Enter: 
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
3. Нажми `Y` (Да) для подтверждения.

### Способ 1: Nativefier (Самый быстрый .exe)
Этот способ создаст папку с `NuxusChat.exe`, который работает как обычная программа.
1. Установи инструмент: `npm install -g nativefier`
2. Создай приложение: `nativefier --name "NuxusChat" --internal-urls ".*" "ТВОЙ_URL_ИЗ_FIREBASE"`
   *(Замени ТВОЙ_URL_ИЗ_FIREBASE на адрес твоего сайта, например https://nuxus-chat.web.app)*

### Способ 2: Установка как PWA (Рекомендуется)
1. Открой сайт в **Google Chrome** или **Microsoft Edge**.
2. В правой части адресной строки появится иконка «монитор со стрелочкой» (**Установить NuxusChat**).
3. Приложение будет запускаться в отдельном окне без вкладок браузера и появится в меню «Пуск».

### Способ 3: Профессиональная сборка (Electron)
Для создания полноценного инсталлятора (Setup.exe):
1. Тебе потребуется создать файл `electron-main.js` и настроить `electron-builder`. Это более сложный путь, требующий навыков разработки на Electron.

## 📱 Как собрать APK для Android
1. Установи Capacitor: `npm install @capacitor/core @capacitor/cli @capacitor/android`
2. Инициализируй проект: `npx cap init NuxusChat com.nuxus.chat`
3. Собери веб-версию: `npm run build`
4. Добавь платформу Android: `npx cap add android`
5. Перенеси файлы: `npx cap copy android`
6. Открой в Android Studio для сборки APK: `npx cap open android`

## 🚀 Развертывание (Деплой)
Чтобы выложить приложение в сеть бесплатно:
1. Залей код на GitHub.
2. В консоли Firebase выбери **App Hosting**.
3. Подключи свой репозиторий.
4. Firebase автоматически выдаст тебе домен `*.web.app`.

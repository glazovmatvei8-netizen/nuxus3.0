
# Nuxus — Инструкция по развертыванию (v0.65.0)

## 📱 Android (APK)
Для сборки используется **Google Bubblewrap**.
1. **VPN**: Обязательно включите перед сборкой для обхода `ECONNRESET`.
2. Команды:
   - `npm install -g @bubblewrap/cli`
   - `bubblewrap init --manifest=https://[ТВОЯ_ССЫЛКА]/manifest.webmanifest`
   - `bubblewrap build`

## 🍎 iOS (iPhone/iPad)

### Метод 1: Нативная сборка (.IPA файл)
Этот метод позволяет получить файл приложения для установки через компьютер.

**1. Подготовка проекта (на ПК):**
```bash
npm install @capacitor/core @capacitor/cli
npx cap init Nuxus chat.nuxus.app
npx cap add ios
```

**2. Компиляция без Mac:**
Так как для Xcode нужен macOS, используйте **GitHub Actions**:
- Создайте репозиторий на GitHub.
- Добавьте workflow для сборки iOS (используйте образ `macos-latest`).
- GitHub выдаст вам готовый файл `App.ipa` в артефактах сборки.

**3. Установка через AltStore / Sideloadly:**
- Скачайте **AltServer** на Windows.
- Установите **AltStore** на iPhone по кабелю.
- Скиньте `.ipa` на iPhone и откройте его через AltStore.
- **Лимит**: Приложение будет работать 7 дней, после чего его нужно обновить через AltStore (потребуется включенный ПК с AltServer в той же Wi-Fi сети).

---

### Метод 2: Web Clip (Рекомендуется для РФ)
Самый простой и надежный способ без ПК и лимитов в 7 дней.
- Откройте ссылку мессенджера в Safari на iPhone.
- Появится экран **«Nuxus App Store»** (я его уже настроил в коде).
- Нажмите «Поделиться» -> «На экран Домой».
- Это создаст иконку, которая работает как полноценное приложение без рамок браузера.

## 💳 Проблема с картой
Кнопка **Publish** требует карту для Firebase App Hosting.
- **Решение**: Используйте временную ссылку Preview для сборки APK/PWA. Все функции (ИИ, база, звонки) работают в облаке напрямую.

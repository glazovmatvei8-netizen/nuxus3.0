
# NuxusChat — Премиальный опыт общения (v24.2.0)

Добро пожаловать в NuxusChat! Приложение полностью оптимизировано для работы как отдельное приложение на Windows, iOS и Android.

## 💻 Установка на ПК (Windows App)
1. Откройте мессенджер в **Google Chrome** или **Microsoft Edge**.
2. В правой части адресной строки нажмите на иконку **«Установить NuxusChat»** (монитор со стрелкой). Это самый надежный способ.

## 📱 Установка на Android (Нативное приложение)
Самый быстрый и рабочий способ для приватных ссылок:
1. Откройте вашу ссылку в Chrome на Android.
2. Нажмите **"Три точки"** в углу.
3. Выберите **"Установить приложение"**.
4. После этого мессенджер появится в меню вашего телефона как полноценная программа с иконкой и без рамок браузера.

### Почему не работает Bubblewrap (APK)?
Ошибка `Unexpected token '<'` означает, что ваша ссылка в Firebase Studio закрыта защитой. Чтобы собрать APK, проект должен быть опубликован на публичный адрес (например, через Firebase Hosting). 

**Решение**: Используйте метод установки через Chrome (PWA), он дает тот же результат, что и APK, но работает мгновенно.


# Nuxus — Премиальный мессенджер

Ваше приложение полностью готово. Ниже подробная инструкция по запуску в сети и сборке.

## 🚀 Как получить публичную ссылку (Деплой на Vercel)

1. **Загрузка на GitHub**: 
   - Распакуйте ZIP в папку.
   - Используйте **GitHub Desktop**, чтобы загрузить папку в новый публичный репозиторий.
2. **Создание ссылки**:
   - Зайдите на [Vercel.com](https://vercel.com) и импортируйте ваш репозиторий.
   - Нажмите **Deploy**. Вы получите ссылку вида `https://nuxus-mauve.vercel.app`.

## 💻 Сборка Desktop-версии (Nativefier)

**Внимание!** Никогда не запускайте команды сборки в `C:\Windows\System32`.
1. Создайте папку на рабочем столе.
2. Откройте в ней терминал.
3. Запустите: `npx nativefier "ТВОЯ_ССЫЛКА_VERCEL" --name "Nuxus" --tray --window-controls`

## 📱 Сборка мобильных приложений (PWABuilder)
1. Зайдите на **PWABuilder.com**.
2. Вставьте вашу ссылку от Vercel.
3. Теперь у вас будет **44/44** балла! Нажмите **Store Package** для получения файлов .apk и .ipa.

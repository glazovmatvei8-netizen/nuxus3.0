## 🚀 Как исправить "Site Not Found" (Деплой)
Чтобы твой сайт заработал по ссылке выше:
1. В этом редакторе (Firebase Studio) нажми на иконку **Firebase** (в левой или верхней панели).
2. Найди кнопку **Deploy** или **Deploy to Hosting**.
3. Дождись завершения процесса. После этого ошибка "Site Not Found" исчезнет.

## 🖥 Как сделать программу для ПК (.exe)

### Шаг 1: Исправление ошибки PowerShell (UnauthorizedAccess)
Если при вводе команд возникает ошибка «выполнение сценариев отключено»:
1. Нажмите Пуск, введите **PowerShell**.
2. Нажмите правой кнопкой на иконку -> **Запуск от имени администратора**.
3. Скопируйте и вставьте эту команду, затем нажмите Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажмите `Y` и Enter. Теперь ошибка исчезнет.

### Шаг 2: Сборка через Nativefier
1. Установите инструмент: `npm install -g nativefier`
2. Создайте приложение командой:
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://studio-5946432351-bbd5e.web.app"`

## 📱 Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход.
- 🔒 **Безопасность**: Уникальные @username, блокировка пользователей.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 📸 **Мультимедиа**: Фото, голосовые и **видео-кружочки** (с предпросмотром и отменой).
- 🤖 **AI Помощник**: Суммаризация чатов и генерация аватарок.

## 🚀 Как запустить как отдельную Windows-программу (EXE)?
Для того чтобы создать папку с приложением и EXE-файлом, скопируйте эту команду и вставьте в **PowerShell** на вашем ПК:

```powershell
npx nativefier --name "NuxusChat" --internal-urls ".*" "ССЫЛКА_ИЗ_БРАУЗЕРА"
```
*(Замените ССЫЛКА_ИЗ_БРАУЗЕРА на ваш актуальный URL-адрес из адресной строки)*.

## ✨ Премиум-функции (уже в коде)
- **Видеосообщения («Кружочки»)**: Нажмите на иконку камеры рядом с полем ввода. Записывайте живое видео в виде круга.
- **Закрепленные сообщения**: Удерживайте сообщение и выберите "Закрепить". Оно появится вверху чата.
- **Глобальный поиск**: Введите `@username` в поиске слева, чтобы найти любой чат или канал.
- **Вступление в группы**: На найденных через поиск чатах теперь есть кнопка «Вступить» или «Подписаться».

## 🛠 Исправление ошибок
Если при регистрации возникает ошибка:
1. Зайдите в **Firebase Console** -> Authentication -> Sign-in method.
2. Включите **Email/Password**.
3. Зайдите в **Settings** -> **Authorized domains** и добавьте туда домен вашей временной ссылки (например, `*.cloudworkstations.dev`).

## 🖥 Как сделать программу для ПК (.exe)

### Шаг 1: Исправление ошибки PowerShell (UnauthorizedAccess)
Если при вводе команд в Windows возникает ошибка «выполнение сценариев отключено»:
1. Нажми Пуск, введи **PowerShell**.
2. Нажми правой кнопкой на иконку -> **Запуск от имени администратора**.
3. Скопируй и вставь эту команду, затем нажми Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажми `Y` и Enter.

### Шаг 2: Сборка через Nativefier
1. Открой обычный терминал или PowerShell.
2. Установи инструмент (если еще не установлен): `npm install -g nativefier`
3. Создай приложение одной командой:
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://studio-5946432351-bbd5e.web.app"`


# NuxusChat — Инструкция по развертыванию (РФ / Без карты)

## 📱 Как создать APK (Android)
Если вы находитесь в РФ или у вас нет зарубежной карты:

1. **Используйте временную ссылку для сборки**: 
   В терминале `bubblewrap init` в поле **Domain** вставьте адрес из адресной строки вашего предпросмотра (тот, который начинается на `9000-...cloudworkstations.dev`). Это позволит собрать APK даже без нажатия кнопки "Publish".
   
2. **Исправление ошибки ECONNRESET (44%)**: 
   Эта ошибка означает, что ваш компьютер не может скачать Android SDK.
   - **Обязательно включите VPN** на компьютере.
   - Убедитесь, что VPN поддерживает протоколы скачивания файлов (некоторые бесплатные VPN могут блокировать такой трафик).

3. **Команды для сборки**:
   - `npm install -g @bubblewrap/cli`
   - `bubblewrap init --manifest=[ВАША_ДЛИННАЯ_URL_ССЫЛКА]/manifest.webmanifest`
   - `bubblewrap build`

## 💳 Ошибка с картой (Billing)
Сервис **App Hosting** (для Next.js SSR) требует карту для активации основного домена. 
- Если карты нет: Мессенджер будет работать внутри Firebase Studio. Вы можете пользоваться им через браузер или собрать APK, используя URL предпросмотра.
- Все данные (сообщения, профили) сохраняются в бесплатной базе Firestore, которой карта не нужна.

# Nuxus — Инструкция по сборке приложений

## 📱 Android (APK)
1. **VPN**: Обязательно включите VPN на ПК.
2. Команды в терминале:
   - `npm install -g @bubblewrap/cli`
   - `bubblewrap init --manifest=https://[ТВОЯ_ССЫЛКА]/manifest.webmanifest`
   - `bubblewrap build`

## 🍎 iOS (iPhone/iPad) — Метод 1: Сборка без Mac

Этот способ позволяет получить файл `.ipa` для установки через AltStore, используя бесплатный "облачный Mac" от GitHub.

### 1. Подготовка (на вашем ПК)
Выполните эти команды в папке проекта:
```bash
npm install
npx cap init Nuxus chat.nuxus.app
npx cap add ios
```

### 2. Сборка через GitHub (Магия)
1. Создайте **новый приватный репозиторий** на GitHub.
2. Загрузите туда весь код проекта (включая папку `.github`, которую я создал).
3. Перейдите на вкладку **Actions** в вашем репозитории на GitHub.
4. Выберите воркфлоу **"Build iOS IPA"** и нажмите **Run workflow**.
5. Через 10-15 минут в разделе "Artifacts" появится готовый файл `Nuxus.ipa`. Скачайте его.

### 3. Установка на iPhone
1. Скачайте программу **AltServer** на ваш Windows-ПК.
2. Установите **AltStore** на iPhone через кабель.
3. Перекиньте скачанный файл `Nuxus.ipa` на iPhone (через iCloud или Telegram).
4. Откройте AltStore на iPhone -> My Apps -> "+" -> Выберите `Nuxus.ipa`.
5. Приложение установлено! 
   *Примечание: Каждые 7 дней нужно "обновлять" подпись в AltStore (телефон и ПК должны быть в одной Wi-Fi сети).*

## 💳 Проблема с картой (Publish)
Если вы не можете привязать карту к Firebase:
1. Не нажимайте кнопку **Publish**.
2. Используйте **длинную временную ссылку** из браузера (Preview) для сборки APK/IPA. 
3. Все функции мессенджера (ИИ, чаты) будут работать напрямую через ваше Ядро в облаке Firebase Studio.

# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени, построенное на NextJS и Firebase.

## Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход по паролю.
- 🔒 **Безопасность**: Уникальные @username, блокировка пользователей и настройки приватности.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 📸 **Мультимедиа**: Фото (до 3Мб), голосовые и **видеосообщения («кружочки»)**.
- 🤖 **AI Помощник**: Генерация черновиков сообщений, суммаризация чатов и **создание AI-аватарок**.
- 🎨 **Кастомизация**: Выбор аватарок, яркие темы и фоны чатов.

## 🖥 Как сделать программу для ПК (.exe)

Если ты хочешь именно отдельный файл **.exe**, а не просто PWA, используй Nativefier.

### Шаг 0: Исправление ошибки PowerShell
Если при вводе `npm install` возникает ошибка «выполнение сценариев отключено» (UnauthorizedAccess), выполни это:
1. Открой **PowerShell от имени Администратора** (Пуск -> введи PowerShell -> Правой кнопкой -> Запуск от имени администратора).
2. Введи команду и нажми Enter: 
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
3. Нажми `Y` (Да) для подтверждения. Теперь ошибки не будет.

### Шаг 1: Получение URL
**ВАЖНО:** Не используй URL, который начинается на `cloudworkstations.dev` — это временная ссылка для разработки.
Тебе нужна ссылка из панели Firebase (раздел Hosting или App Hosting). Она выглядит примерно так: `https://nuxus-chat.web.app`.

### Шаг 2: Сборка через Nativefier
1. Установи инструмент: `npm install -g nativefier`
2. Создай приложение: `nativefier --name "NuxusChat" --internal-urls ".*" "ТВОЙ_ПУБЛИЧНЫЙ_URL"`
   *(Замени ТВОЙ_ПУБЛИЧНЫЙ_URL на адрес своего сайта из Firebase)*

### Способ 2: Установка как PWA (Рекомендуется)
1. Открой публичный сайт в **Google Chrome** или **Microsoft Edge**.
2. В правой части адресной строки появится иконка «монитор со стрелочкой» (**Установить NuxusChat**).
3. Приложение будет запускаться в отдельном окне без вкладок браузера.

## 🚀 Развертывание (Деплой)
Чтобы получить ту самую ссылку для EXE:
1. В консоли Firebase выбери **App Hosting**.
2. Подключи свой GitHub репозиторий.
3. Firebase автоматически выдаст тебе домен `*.web.app`. Используй его для сборки программы.

## Разработка
```bash
npm install
npm run dev
```
Откройте [http://localhost:9002](http://localhost:9002) в браузере.


# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени.

## 🚀 Как поделиться приложением с друзьями?
Временная ссылка `*.cloudworkstations.dev` работает **только у тебя**, пока открыт этот редактор. Чтобы другие могли зайти:

1. **Опубликуй приложение**: Нажми кнопку **"Publish"** или **"Deploy"** в интерфейсе Firebase Studio.
2. **Получи постоянную ссылку**: После деплоя ты получишь URL вида `https://твое-приложение.web.app`.
3. **Отправь ссылку**: Эту ссылку можно открывать в любом браузере на любом устройстве.

## 🔍 Как найти чат или группу?
Если ты создал публичный канал или группу с `@username`:
1. Дай другу свой `@username` (например, `@nuxus_news`).
2. Друг вставляет его в поиск в левой колонке.
3. Чат появится в разделе **"Глобальный поиск"**.
4. Нажав на него, друг сможет нажать кнопку **"Подписаться"** или **"Вступить"**.

## 🖥 Как сделать программу для ПК (.exe)
1. Установи Nativefier: `npm install -g nativefier`
2. Собери EXE (используй свой публичный URL после деплоя):
   `nativefier --name "NuxusChat" --internal-urls ".*" "ТВОЙ_ПУБЛИЧНЫЙ_URL"`

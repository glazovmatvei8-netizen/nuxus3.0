## 🚀 Как получить приложение на iPhone (IPA)

В проекте настроен автоматический билд нативного приложения. Чтобы получить файл `.ipa`:

### Способ 1: GitHub Actions (Автоматически)
1. Перейдите во вкладку **Actions** в этом репозитории на GitHub.
2. Выберите рабочий процесс **Build iOS IPA**.
3. Нажмите кнопку **Run workflow**.
4. После завершения сборки (зеленая галочка) скачайте архив **Nuxus-IPA** внизу страницы.
5. Распакуйте архив, внутри будет файл `Nuxus.ipa`.

### Способ 2: Ручная сборка (Если есть Mac)
Если вы хотите собрать IPA самостоятельно на своем компьютере:
1. Установите зависимости: `npm install`
2. Соберите веб-проект: `npm run build`
3. Синхронизируйте с Capacitor: `npx cap sync ios`
4. Откройте проект в Xcode: `npx cap open ios`
5. В Xcode выберите схему **App**, устройство **Any iOS Device** и нажмите **Product -> Archive**.

## 📲 Установка на iPhone
Установите полученный `.ipa` файл через:
- **AltStore** (рекомендуется)
- **Scarlet**
- **TrollStore**

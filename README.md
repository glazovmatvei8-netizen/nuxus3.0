## ❓ Ответы на вопросы при `firebase init` (на ПК)
Если ты настраиваешь хостинг через консоль на своем компьютере:
- **Configure as a single-page app?** — Выбирай **`y` (Yes)**. Это нужно, чтобы ссылки типа `/settings` работали внутри твоего EXE без ошибок 404.
- **Set up automatic builds with GitHub?** — Выбирай **`n` (No)**.
- **What do you want to use as your public directory?** — Пиши **`out`** (если делаешь статический экспорт) или просто нажми Enter.

## 🖥 Как сделать программу для ПК (.exe)

### Шаг 1: Исправление ошибки PowerShell (UnauthorizedAccess)
Если при вводе команд возникает ошибка «выполнение сценариев отключено»:
1. Нажми Пуск, введи **PowerShell**.
2. Нажми правой кнопкой на иконку -> **Запуск от имени администратора**.
3. Скопируй и вставь эту команду, затем нажми Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажми `Y` и Enter. Теперь ошибка исчезнет навсегда.

### Шаг 2: Сборка через Nativefier
1. Установи инструмент: `npm install -g nativefier`
2. Создай приложение командой:
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://studio-5946432351-bbd5e.web.app"`


# NuxusChat — Публичный запуск (v25.2.0)

Мессенджер полностью оптимизирован для работы как отдельное приложение на Android и iOS.

## 📱 Как установить на iPhone (iOS)
1. Откройте Safari.
2. Перейдите по вашей ссылке (например, `web.app`).
3. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой вверх внизу экрана).
4. Прокрутите меню и выберите **"На экран «Домой»"**.
5. Нажмите **"Добавить"**.
6. **Готово!** Теперь Nuxus будет открываться как полноценное приложение без рамок браузера.

## 📱 Как установить на Android
1. Откройте **Google Chrome**.
2. Нажмите на **"Три точки"** справа вверху.
3. Выберите **"Установить приложение"**.
4. Иконка появится на рабочем столе.

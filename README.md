# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени, построенное на NextJS и Firebase.

## 🌐 Где взять публичный URL для EXE?

Адрес `cloudworkstations.dev` — это временная ссылка для разработчика. Она **не подходит** для создания программы.

Чтобы найти настоящую ссылку:
1. Зайдите в [Firebase Console](https://console.firebase.google.com/).
2. Выберите свой проект.
3. В левом меню найдите раздел **Build** -> **App Hosting** (или **Hosting**).
4. Там будет указан домен, который заканчивается на `.web.app` (например, `https://nuxus-chat-12345.web.app`).
5. **Именно этот URL** используйте для создания EXE.

## 🖥 Как сделать программу для ПК (.exe)

### Шаг 1: Исправление ошибки PowerShell
Если при вводе команд возникает ошибка «выполнение сценариев отключено» (UnauthorizedAccess):
1. Нажмите Пуск, введите **PowerShell**.
2. Нажмите правой кнопкой на иконку -> **Запуск от имени администратора**.
3. Введите эту команду и нажмите Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажмите `Y` и Enter. Теперь ошибка исчезнет.

### Шаг 2: Сборка через Nativefier
1. Установите инструмент (если еще не сделали): `npm install -g nativefier`
2. Создайте приложение (замените URL на свой из шага выше):
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://ВАШ_ПРОЕКТ.web.app"`

## 🚀 Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход.
- 🔒 **Безопасность**: Уникальные @username, блокировка пользователей.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 📸 **Мультимедиа**: Фото, голосовые и **видео-кружочки**.
- 🤖 **AI Помощник**: Суммаризация чатов и генерация аватарок.

## 🚀 Как запустить на macOS
Если система блокирует запуск из-за "неизвестного разработчика":
1. Переместите `Nuxus.app` в папку **Программы** (Applications).
2. Нажмите правой кнопкой на приложение и выберите **Открыть** (Open).
3. В появившемся окне подтвердите запуск кнопкой **Открыть**.
4. После этого Ядро будет запускаться обычным двойным кликом.

## 🚀 Как запустить на Linux
1. Распакуйте архив: `tar -xzvf Nuxus-Linux.tar.gz`.
2. Перейдите в папку и дайте права на выполнение: `chmod +x Nuxus`.
3. Запустите файл `./Nuxus`.
*Рекомендуется создать .desktop файл для интеграции в меню приложений.*

## 🚀 Как запустить EXE на Windows (Обход блокировки)
Если Windows Smart App Control блокирует `Nuxus.exe`:
1. Нажмите правой кнопкой на файл `Nuxus.exe`.
2. Выберите **Свойства** (Properties).
3. На вкладке "Общие" внизу найдите раздел "Безопасность".
4. Поставьте галочку **"Разблокировать"** (Unblock).
5. Нажмите "Применить" и "ОК". 
6. Теперь приложение будет запускаться без ошибок.

## 📦 Сборка через GitHub Actions
Для получения готовых билдов для всех платформ (iOS, macOS, Linux, Windows):
1. Перейти в раздел **Actions** вашего репозитория.
2. Выберите workflow: `Build Desktop` или `Build iOS`.
3. Нажмите **Run workflow**.
4. По завершении скачайте готовые файлы из раздела **Artifacts**.

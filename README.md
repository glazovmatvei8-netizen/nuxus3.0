
# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени.

## ⚠️ Если нет карты для Firebase (Spark Plan)
Поскольку для работы AI (Genkit) и полноценного деплоя Next.js в Firebase требуется план Blaze (с привязкой карты), вот как сделать EXE без этого:

### План Б: Сборка через временный адрес
Если ты не можешь нажать Publish из-за отсутствия карты, используй адрес из адресной строки браузера (тот, что заканчивается на `cloudworkstations.dev`), пока открыт этот редактор.

1. Скопируй адрес из браузера (когда открыто превью приложения).
2. В терминале на ПК введи:
   `nativefier --name "NuxusChat" "ТВОЙ_ВРЕМЕННЫЙ_URL"`
   *Примечание: Такой EXE будет работать только пока запущена рабочая среда в браузере.*

## 🖥 Как сделать программу для ПК (.exe) — Основной способ

### Шаг 1: Исправление ошибки PowerShell (UnauthorizedAccess)
Если в Windows возникает ошибка «выполнение сценариев отключено»:
1. Нажми Пуск, введи **PowerShell**.
2. Нажми правой кнопкой -> **Запуск от имени администратора**.
3. Вставь команду и нажми Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажми `Y` и Enter.

### Шаг 2: Сборка через Nativefier
1. Установи инструмент: `npm install -g nativefier`
2. Создай приложение (используй свой URL):
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://studio-5946432351-bbd5e.web.app"`


# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени, построенное на NextJS и Firebase.

## ⚠️ Важное про публикацию (Deploy)
Для того чтобы сайт заработал по ссылке `.web.app` (и ты смог сделать EXE), проект нужно опубликовать.

### Вариант 1: Полноценный (App Hosting)
Если ты видишь сообщение о **Google Cloud Billing**:
- Firebase просит привязать карту для использования мощностей Google Cloud (это нужно для работы AI и серверных функций).
- У Google есть **бесплатный период** и лимиты, за которые ты вряд ли выйдешь с этим проектом.
- **Плюс**: Будет работать AI-генерация ответов и поиск.

### Вариант 2: Статический (Firebase Hosting)
Если ты не хочешь привязывать карту:
- Можно переключиться на стандартный Hosting (Free Tier).
- **Минус**: AI-функции (кнопка Sparkles) перестанут работать, так как им нужен серверный код.

## 🖥 Как сделать программу для ПК (.exe)

### Шаг 1: Исправление ошибки PowerShell (UnauthorizedAccess)
Если при вводе команд возникает ошибка «выполнение сценариев отключено»:
1. Нажми Пуск, введи **PowerShell**.
2. Нажми правой кнопкой на иконку -> **Запуск от имени администратора**.
3. Скопируй и вставь эту команду, затем нажми Enter:
   `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
4. Нажми `Y` и Enter.

### Шаг 2: Сборка через Nativefier
1. Установи инструмент: `npm install -g nativefier`
2. Создай приложение командой:
   `nativefier --name "NuxusChat" --internal-urls ".*" "https://studio-5946432351-bbd5e.web.app"`

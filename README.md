# NuxusChat — Premium Messaging Experience

Добро пожаловать в NuxusChat! Это современное приложение для общения в реальном времени, построенное на NextJS и Firebase.

## Основные возможности
- 📱 **Вход по номеру телефона**: Быстрая регистрация и вход по паролю.
- 🔒 **Безопасность**: Уникальные @username для каждого пользователя.
- 💬 **Общение**: Приватные чаты, группы и каналы.
- 🤖 **AI Помощник**: Генерация черновиков сообщений и суммаризация чатов.
- 🎨 **Кастомизация**: Выбор аватарок и темы.

## Как установить как программу (Windows / Linux / Android / iOS)
Наше приложение поддерживает технологию **PWA**.
1. Откройте сайт в браузере (Chrome или Edge).
2. В адресной строке нажмите на иконку **«Установить NuxusChat»** (монитор со стрелкой).
3. Приложение появится в меню «Пуск» и на рабочем столе как отдельная программа.

## Развертывание (Деплой)
Чтобы выложить приложение в сеть бесплатно:
1. Залейте код на GitHub.
2. В консоли Firebase выберите **App Hosting**.
3. Подключите свой репозиторий.
4. Firebase автоматически выдаст вам домен `*.web.app`.

## Разработка
```bash
npm install
npm run dev
```
Откройте [http://localhost:9002](http://localhost:9002) в браузере.

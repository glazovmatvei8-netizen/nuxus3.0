
# Nuxus — Премиальный мессенджер (v0.65.8)

## 🚀 Как запустить EXE на Windows (Обход блокировки)
Если Windows Smart App Control блокирует `Nuxus.exe`:
1. Нажмите правой кнопкой на файл `Nuxus.exe`.
2. Выберите **Свойства** (Properties).
3. На вкладке "Общие" внизу найдите раздел "Безопасность".
4. Поставьте галочку **"Разблокировать"** (Unblock).
5. Нажмите "Применить" и "ОК". 
6. Теперь приложение будет запускаться без ошибок.

## 🚀 Сборка Windows EXE в один файл
Nativefier создает папку с файлами. Чтобы получить ОДИН файл:
1. Используйте программу **Enigma Virtual Box**.
2. В поле "Input File Name" выберите `Nuxus.exe`.
3. В "Files Tree" добавьте всю папку из Nativefier через "Add Folder Recursive".
4. Нажмите **Process**. Полученный файл `Nuxus_boxed.exe` — это один переносимый файл.

## 🚀 Как обновить иконку (v45)
1. Введите в терминале: `sh push.sh`.
2. Через минуту сайт обновится автоматически. Ядро принудительно закрепило иконку v45 для всех узлов.


# Nuxus — Премиальный мессенджер (v0.65.8)

Ваше приложение полностью готово к работе в режиме PWA, мобильного APK и десктопа.

## 🚀 Как синхронизировать изменения за 5 секунд

Если вы попросили меня что-то исправить (например, иконку), и я сказал "Я всё сделал", вам нужно отправить эти изменения в ваш GitHub, чтобы они появились на Vercel:

1.  Внизу экрана в Firebase Studio найдите панель **TERMINAL**.
2.  Введите команду: `sh push.sh` и нажмите **Enter**.
3.  Через минуту ваш сайт на Vercel обновится автоматически!

## 🚀 Как правильно перенести проект на Vercel (вручную)

1. **Войдите в режим кода**: В верхнем правом углу экрана Firebase Studio нажмите на иконку **`< />`**.
2. **Скачайте исходный код**: 
   - В левой панели **EXPLORER** найдите папку **STUDIO** (самая верхняя).
   - Нажмите ПРАВОЙ кнопкой мыши на название папки **STUDIO**.
   - Выберите **Download**. Проект скачется как один `.zip` архив.
3. **GitHub**: Распакуйте архив и загрузите все файлы в ваш репозиторий на GitHub.
4. **Vercel**: Подключите репозиторий к Vercel и нажмите **Deploy**.

## 📱 Сборка Android APK
1. Получите ссылку от Vercel (например, `https://nuxus-app.vercel.app`).
2. Зайдите на сайт **[PWABuilder.com](https://www.pwabuilder.com/)**.
3. Вставьте ссылку на ваш сайт.
4. Нажмите **Build APK**.

## ⚠️ Решение ошибок сборки (Troubleshooting)

### Ошибка: `cli ERROR EPERM: operation not permitted, open 'C:\WINDOWS\system32\...'`
**Что это значит:** Вы пытаетесь запустить команду сборки, находясь в системной папке Windows. Система безопасности запрещает создавать там файлы.

**Как исправить:**
1. Закройте консоль.
2. Перенесите папку с проектом из системных папок в обычную (например, в «Загрузки», в «Документы» или на диск D:).
3. В строке пути (вверху окна проводника) удалите всё, напишите `cmd` и нажмите Enter.
4. Теперь вы можете запускать команды сборки.

## 🚀 Как решить ошибку "Не удалось отправить SMS"?
Если при вводе номера телефона возникает ошибка:
1. **Авторизуйте домен**: Зайдите в [Firebase Console](https://console.firebase.google.com/) -> Authentication -> Settings -> Authorized domains. Добавьте туда домен своей рабочей станции (из адресной строки браузера, без https://).
2. **Включите провайдер**: Authentication -> Sign-in method -> Включите **Phone**.
3. **Белый список**: Если используете временную ссылку, Firebase может блокировать её как подозрительную. Лучший способ — нажать **Publish** и использовать ссылку `*.web.app`.

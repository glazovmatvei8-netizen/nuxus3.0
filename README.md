
# Nuxus — Инструкция по сборке

Ваше приложение оптимизировано для прохождения валидации **PWABuilder**.

## 🚀 Как собрать APK/IPA сейчас:

1. **Опубликуйте изменения**: Убедитесь, что вы нажали "Publish" в Firebase Studio (если доступно) или используйте текущую Preview-ссылку.
2. **PWABuilder**: Зайдите на [PWABuilder.com](https://www.pwabuilder.com/).
3. **Ссылка**: Вставьте ссылку на ваш мессенджер. 
4. **Результат**: Теперь все пункты (Icons, Service Worker, Screenshots) должны быть отмечены зелеными галочками.
5. **Сборка**: Нажмите "Store Package" и скачайте пакеты для Android и iOS.

### 🍏 iOS (iPhone) без App Store:
Пользователи могут просто нажать кнопку "Поделиться" -> "На экран Домой". Благодаря настроенному `manifest.ts` и `sw.js`, приложение будет выглядеть и работать как нативное.

### 📱 Android:
Скачайте APK с PWABuilder и установите его на устройство. Все функции, включая ИИ и уведомления, будут работать внутри нативной оболочки.


# Nuxus — Инструкция по сборке APK (РФ / Без карты)

Если вы находитесь в РФ или у вас нет зарубежной карты для оплаты хостинга, следуйте этой инструкции для создания мобильного приложения.

## 📱 Как создать APK (Android)

Для сборки используется инструмент **Google Bubblewrap**. 

### 1. Решение ошибки ECONNRESET (44%)
Эта ошибка означает, что ваш компьютер не может скачать Android SDK от Google.
- **ОБЯЗАТЕЛЬНО ВКЛЮЧИТЕ VPN** на компьютере перед запуском команд.
- Если VPN не помогает, попробуйте сменить провайдера (например, раздать интернет с телефона с включенным на нем VPN).
- Проверьте, что у вас установлен Node.js версии 16+.

### 2. Сборка без нажатия кнопки "Publish"
Так как кнопка Publish требует карту, мы будем собирать APK, используя временную ссылку предпросмотра (Preview).

**Команды для сборки:**
1. Установите CLI: `npm install -g @bubblewrap/cli`
2. Перейдите в пустую папку на ПК.
3. Запустите инициализацию:
   `bubblewrap init --manifest=https://[ВАША_ДЛИННАЯ_ССЫЛКА_ПРЕДПРОСМОТРА]/manifest.webmanifest`
   *(Длинная ссылка — это адрес из браузера, начинающийся на 9000-firebase-studio...)*
4. На вопрос про **Domain** вставьте: `[ВАША_ДЛИННАЯ_ССЫЛКА_ПРЕДПРОСМОТРА]` (без https:// и путей).
5. На все остальные вопросы нажимайте **Enter** (выбирайте `standalone`).
6. В конце запустите: `bubblewrap build`

## 💳 Проблема с картой
Кнопка **Publish** требует карту, так как использует Firebase App Hosting. 
- **Решение**: Просто не нажимайте её. Все функции мессенджера (база данных, AI, звонки) уже работают в облаке. APK будет подключаться к ним напрямую через временную ссылку.

## 🍎 iOS (iPhone/iPad) — Сборка через GitHub (БЕЗ MAC И БЕЗ VPN)

Этот метод работает, потому что сборка идет на серверах GitHub в США.

### 1. Загрузка кода
1. Создайте аккаунт на [github.com](https://github.com).
2. Создайте новый **приватный** репозиторий.
3. Загрузите туда все файлы этого проекта (просто перетащите мышкой в браузер).

### 2. Запуск сборки
1. На странице вашего репозитория на GitHub нажмите вкладку **Actions**.
2. Слева выберите **"Build iOS IPA"**.
3. Нажмите кнопку **Run workflow** -> **Run workflow**.
4. Подождите 10-15 минут. Когда появится зеленая галочка, внизу страницы в разделе "Artifacts" появится файл `Nuxus-IPA`.

### 3. Установка на iPhone
1. Скачайте файл `.ipa` на компьютер.
2. Используйте [Sideloadly](https://sideloadly.io/) (она обычно работает без VPN) или AltStore.
3. Подключите iPhone кабелем и установите файл.

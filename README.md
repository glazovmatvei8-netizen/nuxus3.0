
# Nuxus — Инструкция по развертыванию (v0.60.0)

## 📱 Android (APK)
Для сборки используется **Google Bubblewrap**.
1. **VPN**: Обязательно включите перед сборкой для обхода `ECONNRESET`.
2. Команды:
   - `npm install -g @bubblewrap/cli`
   - `bubblewrap init --manifest=https://[ТВОЯ_ССЫЛКА]/manifest.webmanifest`
   - `bubblewrap build`

## 🍎 iOS (iPhone/iPad)
На iOS нет прямого способа установить файл как APK без App Store, но есть альтернативы:

### 1. Метод «Web Clip» (Рекомендуется)
При открытии ссылки мессенджера на iPhone появится экран **«Nuxus App Store»**.
- Нажмите «Поделиться» -> «На экран Домой».
- Это создаст иконку на рабочем столе, которая работает как полноценное приложение (без рамок браузера).

### 2. Sideloading (IPA файл)
Если вам нужен именно нативный файл для установки через **AltStore**, **Sideloadly** или **Scarlet**:
1. Нужно собрать проект через Capacitor: `npx cap add ios`.
2. Скомпилировать `.ipa` (требуется Mac или GitHub Actions).
3. Установить через AltStore (требуется компьютер, обновление каждые 7 дней).

## 💳 Проблема с картой
Кнопка **Publish** требует карту для Firebase App Hosting.
- **Решение**: Используйте временную ссылку Preview для сборки APK/PWA. Все функции (ИИ, база, звонки) работают в облаке напрямую.

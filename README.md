
# Nuxus — Инструкция по сборке (Без VPN и Mac)

Если у вас **заблокированы** сайты разработчиков (Capacitor, Google) и **нет VPN**, используйте только метод сборки в облаке через онлайн-сервисы.

## 🚀 Лучшие онлайн-генераторы (Вставил ссылку — получил файл)

Эти сайты сами соберут приложение за вас. Просто вставьте ссылку на ваш мессенджер: 
`https://studio-5946432351-bbd5e.web.app/`

### 1. [PWABuilder](https://www.pwabuilder.com/) (Рекомендуется ⭐)
*   **Создатель:** Microsoft.
*   **Что делает:** Самый качественный APK для Android и пакет для iOS.
*   **Плюс:** Бесплатно, официально, проходит все проверки безопасности.

### 2. [PWA2APK](https://app-maker.pwa2apk.com/)
*   **Что делает:** Быстро превращает ваш URL в Android APK.
*   **Плюс:** Минимум настроек, работает «из коробки».

### 3. [WebIntoApp](https://www.webintoapp.com/)
*   **Что делает:** Поддерживает Android и iOS.
*   **Плюс:** Позволяет легко настроить иконку и экран загрузки прямо на сайте.

## 📱 Как получить файлы проекта на ПК?
Если вы хотите загрузить файлы на GitHub для ручной сборки:
1. В интерфейсе Firebase Studio найдите кнопку **"Download Project"** (обычно это иконка облака или стрелки вниз).
2. Весь код будет скачан в одном архиве `.zip`.
3. Распакуйте его и загрузите в свой репозиторий на GitHub.

## 🍎 iOS (iPhone/iPad) — Сборка через GitHub Actions

Этот метод работает, потому что сборка идет на серверах GitHub в США.

1. Загрузите код в **приватный** репозиторий на GitHub.
2. Нажмите вкладку **Actions**.
3. Слева выберите **"Build iOS IPA"**.
4. Нажмите **Run workflow**. 
5. Через 15 минут в разделе "Artifacts" появится файл `Nuxus-IPA`.

**Nuxus — Твое Ядро работает вне зависимости от блокировок.**


# NuxusChat — Инструкция для РФ (Без карты / Ошибка 44%)

## 📱 Как создать APK (Android)
Если вы находитесь в РФ или у вас нет зарубежной карты:

1. **Используйте ссылку предпросмотра**: 
   В терминале `bubblewrap init` в поле **Domain** вставьте адрес из адресной строки вашего браузера (тот, который начинается на `9000-firebase-studio...cloudworkstations.dev`). Это позволит собрать APK без нажатия кнопки "Publish".
   
2. **Исправление ошибки ECONNRESET (44%)**: 
   Эта ошибка означает, что ваш компьютер не может скачать Android SDK от Google.
   - **ОБЯЗАТЕЛЬНО ВКЛЮЧИТЕ VPN** на компьютере перед запуском команд.
   - Если VPN не помогает, попробуйте сменить провайдера (например, раздать интернет с телефона).

3. **Команды для сборки**:
   - `npm install -g @bubblewrap/cli`
   - `bubblewrap init --manifest=https://[ВАШ_URL_ПРЕДПРОСМОТРА]/manifest.webmanifest`
   - `bubblewrap build`

## 💳 Ошибка с картой (Publish)
Кнопка **Publish** требует карту, так как использует сервис App Hosting. 
- **Решение**: Просто не нажимайте её. Мессенджер уже работает в облачной среде Firebase Studio. Вы можете пользоваться им через браузер или через APK, собранный по инструкции выше.
- База данных (Firestore) и Аутентификация продолжат работать бесплатно без привязки карты.

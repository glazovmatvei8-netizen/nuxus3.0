## 💳 Проблема с биллингом (Карты РФ)
Если Google требует карту для «Publish», а у вас её нет, вот варианты:

1. **Использование Preview-ссылки**: Вы можете открыть в браузере телефона ту длинную техническую ссылку, которую дает Firebase Studio. Если она на HTTPS, кнопка «Установить» в Chrome всё равно может сработать.
2. **Бесплатные хостинги (Vercel/Netlify)**: Если Firebase блокирует запуск без карты, этот же код можно бесплатно выгрузить на Vercel. Они не требуют карту для простых проектов.
3. **Виртуальные карты**: Сервисы вроде *Pyypl* или зарубежные друзья.

## 📱 Установка на Android (PWA)
Я добавил файл `sw.js`. Теперь при открытии сайта в **Google Chrome** на телефоне:
1. Нажмите **"Три точки"**.
2. Выберите **"Установить приложение"**.
3. Иконка Nuxus появится на рабочем столе.


# NuxusChat — Публичный запуск (v0.52.0)

Мессенджер полностью оптимизирован для работы как отдельное приложение на Android и iOS.

## 🍎 Как установить на iPhone (Способ 1: Стандартный)
1. Откройте **Safari** (обязательно Safari, не Chrome!).
2. Перейдите по ссылке `https://studio-5946432351-bbd5e.web.app/`.
3. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой вверх внизу экрана).
4. Прокрутите меню вниз и выберите **"На экран «Домой»"**.
5. Нажмите **"Добавить"**.

## 🍎 Если кнопки нет (Способ 2: Быстрые команды)
Если Safari прячет кнопку, можно сделать приложение вручную:
1. Откройте приложение **"Команды"** (Shortcuts) на iPhone.
2. Нажмите **"+"** вверху справа.
3. Нажмите **"Добавить действие"** -> Поиск: **"Открыть URL"**.
4. Вставьте ссылку: `https://studio-5946432351-bbd5e.web.app/`.
5. Нажмите на название команды вверху -> **"На экран «Домой»"**.
6. Выберите имя "Nuxus" и любую иконку из галереи.

## 📱 Как установить на Android
1. Откройте **Google Chrome**.
2. Перейдите на сайт.
3. Нажмите на **"Три точки"** справа вверху.
4. Выберите **"Установить приложение"**.

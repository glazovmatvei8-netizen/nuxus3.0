## 🚀 Как решить ошибку "Ошибка авторизации"?
Если при регистрации или входе возникает ошибка:
1.  **Включите провайдер**: Зайдите в [Firebase Console](https://console.firebase.google.com/) -> Authentication -> Sign-in method.
2.  Нажмите **Add new provider** и выберите **Email/Password**.
3.  Включите его (**Enable**) и нажмите **Save**. 
4.  *Это необходимо, так как мы используем виртуальные почты для работы без SMS и банковских карт.*

## ✨ Новые функции
- **Видеосообщения («Кружочки»)**: Нажмите на иконку камеры рядом с полем ввода, чтобы записать видео в реальном времени.

- **Глобальный поиск**: Введите `@username` в поиске слева. Вы сможете найти любой публичный чат или канал и вступить в него одной кнопкой.

## 🚀 Как решить ошибку "Ошибка авторизации"?
Если при регистрации или входе возникает ошибка:
1.  **Включите провайдер**: Зайдите в [Firebase Console](https://console.firebase.google.com/) -> Authentication -> Sign-in method.
2.  Нажмите **Add new provider** и выберите **Email/Password** (Электронная почта/пароль).
3.  Включите его (**Enable**) и нажмите **Save**. 
4.  *Мы используем этот метод для входа по Телефону + Паролю, чтобы работать без SMS и привязки банковских карт.*

## ✨ Новые премиум-функции
- **Видеосообщения («Кружочки»)**: Нажмите на иконку камеры рядом с полем ввода. Записывайте живое видео в виде идеального круга.
- **Закрепленные сообщения**: Удерживайте сообщение или нажмите на него, выберите "Закрепить". Оно появится вверху чата для всех.
- **Глобальный поиск**: Введите `@username` в поиске слева, чтобы найти любой чат или канал.
- **Вступление в группы**: На найденных через поиск чатах теперь есть кнопка «Вступить» или «Подписаться».

## ⚡ Техническая оптимизация
- **Авто-скролл вниз**: Все чаты открываются на самых свежих сообщениях.
- **Кнопка возврата**: Появилась кнопка со стрелочкой вниз для быстрого перехода к новым сообщениям.
- **Anti-Lag**: Сигналы печати отправляются не чаще чем раз в 3.5 сек, что убирает фризы при быстром наборе.
- **Security**: Внедрен App Check и строгие правила Firestore для защиты ваших данных.

## 🔗 Как запустить на Windows?
Просто скопируйте URL-адрес текущей страницы (превью) и откройте его в браузере на вашем ПК. Ссылка будет работать, пока открыта эта рабочая станция.

## 🚀 Как синхронизировать изменения за 5 секунд

Если вы попросили меня что-то исправить (например, иконку), и я сказал "Я всё сделал", вам нужно отправить эти изменения в ваш GitHub, чтобы они появились на Vercel:

1.  Внизу экрана в Firebase Studio найдите панель **TERMINAL**.
2.  Введите команду: `sh push.sh` и нажмите **Enter**.
3.  Через минуту ваш сайт на Vercel обновится автоматически!

## 🚀 Сборка Windows EXE (Правильный способ)

Nativefier создает папку с множеством файлов, так как это Electron-приложение. Чтобы получить **один файл .exe** и правильную иконку:

1. **Скачайте иконку** себе на компьютер в формате `.ico` или `.png`.
2. **Используйте команду с иконкой**:
   ```bash
   npx nativefier "ВАША_ССЫЛКА_НА_VERCEL" --name "Nuxus" --icon "C:\path\to\icon.png" --internal-urls ".*" --single-instance --tray --window-controls
   ```
3. **Чтобы сделать один файл**: Используйте бесплатную программу **Enigma Virtual Box**. Выберите ваш `Nuxus.exe`, добавьте в нее все остальные файлы из папки и нажмите «Process». Вы получите один переносной `.exe`.

## ⚠️ Решение ошибок сборки (Troubleshooting)

### Ошибка: `cli ERROR EPERM: operation not permitted`
**Что это значит:** Вы пытаетесь запустить команду в папке `C:\Windows\system32`. Windows запрещает там создавать файлы.
**Как исправить:** Перенесите папку с проектом в «Документы» или на диск D:. Откройте консоль там и запустите команду снова.


# Nuxus — Премиальный мессенджер (v0.65.0)

Ваше приложение полностью готово к работе в режиме PWA, мобильного APK и десктопа.

## 🚀 Как правильно перенести проект на Vercel

Инструменты типа `sitecopy.ru` **не работают** с этим проектом, так как это динамическое приложение Next.js. Используйте этот метод:

1. **Скачайте исходный код**: В левой панели файлов Firebase Studio нажмите правой кнопкой на корень проекта и выберите **Download** (или используйте кнопку экспорта в верхней панели).
2. **Создайте репозиторий**: Зайдите на [GitHub](https://github.com), создайте новый репозиторий (например, `nuxus-app`).
3. **Загрузите файлы**: Используйте GitHub Desktop или команду `git push`, чтобы загрузить скачанные файлы в репозиторий.
4. **Деплой на Vercel**: 
   - Зайдите на [Vercel.com](https://vercel.com).
   - Нажмите **Add New** -> **Project**.
   - Импортируйте ваш репозиторий `nuxus-app`.
   - **ВАЖНО**: В настройках проекта на Vercel добавьте переменные окружения (Environment Variables), если они у вас есть в `.env`.
   - Нажмите **Deploy**.

## 📱 Сборка Android APK (через PWABuilder)
1. Получите ссылку от Vercel (например, `https://nuxus-app.vercel.app`).
2. Вставьте её на **PWABuilder.com**.
3. Нажмите **Package for Stores** -> **Android**.
4. Убедитесь, что Package ID указан как `chat.nuxus.app`.
5. Скачайте готовый `.apk`.

## 💻 Сборка Desktop-версии (Nativefier)
1. Откройте терминал на диске `D:\`.
2. Введите: `cd Nuxus-app`
3. Запустите: `npx nativefier "ВАША_ССЫЛКА_VERCEL" --name "Nuxus" --tray --window-controls --internal-urls ".*" --single-instance`

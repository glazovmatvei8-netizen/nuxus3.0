## 🚀 Как запустить как отдельную программу?

### Для Windows (PowerShell):
Создает папку с EXE-файлом на рабочем столе:
```powershell
npx nativefier --name "NuxusChat" --internal-urls ".*" "ССЫЛКА_ИЗ_БРАУЗЕРА"
```

### Для Linux (Terminal):
Создает исполняемый файл для Linux:
```bash
npx nativefier --name "NuxusChat" --platform "linux" --internal-urls ".*" "ССЫЛКА_ИЗ_БРАУЗЕРА"
```
*(Замените ССЫЛКА_ИЗ_БРАУЗЕРА на ваш актуальный URL из адресной строки)*.

## 🛠 Исправление ошибок регистрации
Если при регистрации возникает ошибка:
1. Зайдите в **Firebase Console** -> Authentication -> Sign-in method.
2. Включите **Email/Password**.
3. В разделе **Settings** -> **Authorized domains** добавьте домен вашей временной ссылки.
